6.6 Request Flow (HTTPS):-
 Fig 6.4: How a browser request travels through DuckDNS, Nginx, FastAPI and PostgreSQL
When a user opens the website, the browser first asks DuckDNS for the IP address of the domain. It
then opens an encrypted HTTPS connection to Nginx on the EC2 instance. Requests for pages are
answered directly by Nginx from the React build, while every request beginning with /api or /static
is forwarded to the FastAPI container on 127.0.0.1:8000. FastAPI queries PostgreSQL and returns
JSON (or an image), which Nginx sends back to the browser over the same secure connection.

6.7 SSL Certificate Flow (Certbot + Let’s Encrypt):-
 Fig 6.5: Obtaining and renewing the SSL certificate with Certbot
Let’s Encrypt issues a certificate only after verifying that the requester controls the domain. Certbot
places a temporary token file on the Nginx server; Let’s Encrypt resolves the DuckDNS domain and
downloads the token over port 80. Once the token matches, the signed certificate is returned, Certbot
updates the Nginx configuration for HTTPS and reloads Nginx. The certbot systemd timer repeats
this process automatically before the certificate expires.

 ADVANTAGES
7.1 Advantages:-
The FurniFlex web application developed using React, FastAPI and PostgreSQL provides several
key advantages that enhance the functionality, reliability and usability of the furniture rental
platform:
1. Affordable and Flexible Renting:
Customers can rent furniture on Monthly, Quarterly or Yearly plans with automatic discounts for
longer durations, avoiding the large up-front cost of buying furniture.
2. Server-side Cart:
The cart is stored in the database against the logged-in user, so items remain available even after the
browser is closed or when the customer logs in from another device.
3. Secure Authentication and Role-based Access:
Passwords are hashed with bcrypt and every request is authenticated with a signed JWT token.
Admin APIs are protected on the server side, so a customer cannot access them even by calling the
API directly.
4. Device Flexibility and Modern UI:
The responsive Material UI design works on laptops, tablets and smartphones, and supports both
light and dark modes, which are remembered for the next visit.
5. Simplified Catalogue Management:
Administrators can add, edit and delete products and categories and upload images directly from the
admin panel without touching the code or the database.
6. Accurate Order Records:
Each order item stores the price at the time of ordering and the selected rental plan, so historical
orders remain correct even if product prices change later.
